## Overview

A nonfiction, true-crime or local-history writer already ties passages to Sources with citations, but the citations stay inside the app: when the manuscript is compiled for an editor or a class, they vanish, and the writer rebuilds every note and the bibliography by hand in a word processor, on every draft. This feature adds a switchable first-party module, off by default, in which a Source carries a fixed set of bibliographic fields for four reference types (book, article, web page, interview), the compile dialog offers a citations switch and a bundled style, and a PDF or DOCX compiled with the switch on carries each citation as a footnote or an in-text reference, as the style says, and ends with a bibliography of the cited Sources. The writer is told before the run which citations cannot be rendered in full, and an incomplete citation is rendered with a visible marker and never dropped. With the switch or the module off, compile is unchanged in every format. Which citation engine is used is not decided: one candidate, Hayagriva compiled to WebAssembly, is checked first, and the owner's decision to accept it and its licences, and those of the style and the locale, comes before any engine-dependent work.

## Goals

- A writer can enter a Source's bibliographic details for a book, article, web page or interview in fixed fields on the Source, see which details the bundled style still needs, and keep those fields apart from custom fields, with the module on and the Sources module on or off.
- A writer can compile to PDF or DOCX on desktop and hosted web with citations on, in the bundled style, and get each citation of a compiled resource as a footnote or in-text reference and a bibliography of the cited Sources, with locators in the style's terms.
- A writer is told before the run, grouped by Source with a count, which citations cannot be rendered in full, can proceed or cancel, and finds on proceed a visible marker for each, never a skipped citation and never a refused compile.
- With the module off, or the switch off, compile output is identical to today in TXT, Markdown, DOCX and PDF, and switching the module off deletes nothing.
- The engine (Hayagriva, if the owner accepts it), its licence and the bundled style are settled by a recorded feasibility check and an owner decision before any engine-dependent work starts, with attribution shown to the writer.

## Non-goals

- Any style beyond the one bundled style, a project default style (Feature 117, Product FR-223), a later-note rule of GetWrite's own, the archival item and recording types (Feature 117), and a bibliography of every Source (Feature 119).
- Markdown and plain-text citations, Android compile with citations, and the in-app PDF path claims (Feature 118; Product FR-224 and the Android part of FR-225).
- A reference manager, Zotero sync, a podcast or script compile format, checking that a citation or quote is correct, `.csl` import, BibTeX, CSL-JSON or DOI import, citations in the Compile Entity Resources dialog, and citations in export.
- A change to how a citation is made or stored, a where-cited index, and any change to the Sources module, the claim ledger, Document status or `config.statuses`.
- Non-English locales, and any guided pass over the Sources (a v1 candidate).

## User stories

- US-1: As a nonfiction, true-crime or local-history writer who cites books, articles, web pages and interviews, I want to enter each Source's bibliographic details once in fixed fields and see which details the chosen style still needs so that I can fix gaps while I enter them. (Product US-53.)
- US-2: As a nonfiction, true-crime or local-history writer, I want to switch citations on when I compile to PDF or DOCX and pick a bundled style so that my cited passages become footnotes or in-text references with a bibliography of the Sources I cited, without rebuilding them by hand. (Product US-53.)
- US-3: As a student, academic or folklore writer who must hand in a named style, I want to see before I compile which citations cannot be rendered, grouped by Source, so that I do not discover gaps in the output. (Product US-54.)
- US-4: As a writer who does not cite, I want to keep citations off until I switch them on, with my compiled output and my data unchanged when they are off, so that I never see the module unless I want it and never lose work by turning it off. (Product FR-210, FR-214, FR-228.)
- US-5: As a GetWrite owner, I want to accept or reject the citation engine (one candidate, Hayagriva), with its licence and those of the bundled style and locale, after a recorded feasibility check so that GetWrite never ships an engine whose licence or runtime was assumed. (Product FR-226, OQ-246.)
