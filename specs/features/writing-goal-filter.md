## Overview

A writer's goal figures count every document in the project. The total word-count goal sums the words of the resources the Data view is given, and the daily goal sums every non-import entry in today's writing log (Read, not run: `frontend/components/WorkArea/DataView.tsx:159-162`; `frontend/src/lib/models/writing-log-core.ts:145-154`). Notes, research and set-aside drafts therefore inflate progress. This feature lets a writer set conditions, with the same query builder used for smart folders, that choose which documents count toward both goals, and makes every filtered figure say that it is filtered. A figure that cannot be computed must say so and must not show a number.

## Goals

- A writer can set, change and clear one filter, in the Writing Goals tab of Project Settings, that decides which text documents count toward both the total word-count goal and the daily goal.
- With a filter set, the total goal's progress and today's daily figure count only matching, live text documents, evaluated when the figure is read.
- Every filtered figure carries a neutral text label; a filter that matches nothing shows a real zero and says so; a figure that could not be computed shows an unavailable line and never a number.
- With no filter set, both goals behave exactly as they do today.
- Web, desktop and Android give the same figure for the same project and filter, and a stored filter that is invalid or names a missing field is shown to the writer rather than silently ignored.

## Non-goals

- The per-document goal (`wordCountGoal` on a text sidecar, FR-47) is not filtered or changed.
- Imported words counting toward the daily goal. Imports stay on their separate line (FR-48) and never count toward it.
- Backfilling or guessing a document for writing-log entries written before this feature (FR-79 (4)).
- Storing the filter as a reference to a saved query (FR-79 (3)), or any change to smart-folder behaviour, saved queries or the Data view's smart-folder filtering.
- Two separate filters, one per goal (FR-79 (2): one filter covers both).
- Seeding a filter from a project type, or changing what project types seed. A project type never carries, seeds or captures a filter (decided, Resolved questions RQ-11).
- A live count of matching documents in the Goal filter section (RQ-10).
- A cache, index or precomputed figure. None is added until the measurement task in FR-39 is recorded.
- Streaks, history views or charts of filtered figures.

## User stories

- US-1: As a writer on deadline, I want to choose which of my documents count toward the project's total word-count goal so that notes, research and set-aside drafts do not inflate my progress.
- US-2: As a writer on deadline, I want to apply the same choice to my daily goal so that today's figure counts only the writing I mean to count.
- US-3: As a writer, I want to see that every filtered figure is filtered, and to tell a zero that is real from a figure that could not be computed, so that I never act on a number I cannot trust.
- US-4: As a writer who has just upgraded, I want to be told when today's filtered figure leaves out earlier writing that cannot be attributed to a document so that I do not read a low figure as my whole day.
- US-5: As a writer using the desktop app, a paired device or the Android app, I want to get the same filter behaviour everywhere so that my goals do not differ by device.
