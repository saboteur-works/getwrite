# Search

Press **Cmd+K** or **Ctrl+K** to open search, start typing a document's name, and open it from the results. Click a result to open it; with a single result, pressing **Enter** opens it.

On macOS both shortcuts moved focus to the search field. Windows and Linux were not run.

None recorded.
