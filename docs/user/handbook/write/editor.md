# Rich Text Editor

When you open a text document, GetWrite gives you a rich-text editor.

## Format your text

Select text and use the toolbar to apply bold, italic, underline, strikethrough or inline code.

On a Mac, **Cmd+B**, **Cmd+I** and **Cmd+U** apply bold, italic and underline to the selected text.

## Check your word count

A live word count appears in the footer as you type, for example `Words: 8`.

## How your work is saved

GetWrite saves your text about 2.5 seconds after you stop typing. The footer then says **All changes saved**.

If you open another document before then, GetWrite saves your text to the document you typed in straight away. If that save fails, a message says "Your last edits to the previous document were not saved". Open that document again to check its content.

If you close the project before then, a **Close project?** prompt says you have unsaved changes that may still be syncing. Choose **Keep Editing** to stay in the project, or **Close Project** to return to the Start Page. Your text is saved either way.

In the browser, your text is also saved if you reload the page before then.

## Write in Markdown

To write in plain text, select **Edit as Markdown** in the toolbar and confirm. GetWrite converts the document to Markdown and swaps the rich-text editor for a plain-text one.

The conversion is one-way. The prompt lists what will be removed, which can include text colours, custom fonts and sizes, text alignment and paragraph line spacing. Switching back to rich text doesn't bring these back.

## Good to know

- In the desktop app, your last words can be lost if you close the window straight after typing. Before you close the window, wait until the footer says **All changes saved**.
