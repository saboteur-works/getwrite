# Data View

The Data View gives you an overview of a project. Open the **Data** tab to see it. Its heading is the project's name followed by "Overview".

## Read the totals

- **Resources:** how many resources the project holds. Documents and images are counted, and folders aren't.
- **Total words:** the number of words in all the project's documents. The words in your Sources are included here, even though they don't count toward your word goals unless your goal filter selects them.

When you select a smart folder in the resource tree, these two figures count only what the smart folder shows.

## See your documents by status

The **By status** table shows how many documents have each status, and how many words they hold between them. It has three columns: **Status**, **Resources** and **Words**.

- The rows follow the order of the project's statuses, including statuses no document has yet, which show 0.
- A status a document still has, but which is no longer in the project's list, gets its own row marked "(not in the current list)".
- Documents with no status are counted in the last row, **No status**.
- If the project has no statuses, the section says so, and every document is counted under **No status**. See [Project Configuration](../protect-and-finish/project-configuration.md) for how a project's statuses are set.
- A project with no documents shows "No text resources yet." instead of the table.

The table counts documents only, across the whole project. It doesn't change when you select a smart folder.

## Find recent and short documents

The **Resources** list shows each resource with its kind, its word count and when it was last updated. It lists the most recently edited first. Choose **Name** to sort by name, or **Last edited** to go back.

Resources of 50 words or fewer are listed first, under **Needs content**. The others follow.
