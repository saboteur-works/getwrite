# GetWrite Handbook

## Getting started

- [Installing GetWrite](getting-started/installing.md) — Where GetWrite keeps your projects on disk and what a project folder contains.

## Organize

- [Start Page](organize/start-page.md) — The first page of GetWrite, where you create, open, rename, delete, compile and import projects.
- [Project Types](organize/project-types.md) — The six built-in project types, the folders and starter documents each creates, and the Project Type Manager.
- [Resource Tree](organize/resource-tree.md) — The panel that lists a project's documents, images, audio and folders, and how to create, rename, move and reorder them.

## Write

- [Rich Text Editor](write/editor.md) — The text editor you write in, with toolbar formatting, keyboard shortcuts and a live word count in the footer.
- [Daily Writing Log](write/writing-log.md) — How GetWrite records the words you write each day, shows today's figure against an optional goal, and what it counts.
- [Headings](write/headings.md) — Apply heading levels in the editor and set how each level looks for a project.
- [Editor Appearance](write/editor-appearance.md) — What sets the look of the writing surface and the body text and heading settings you can change in a project.
- [Search](write/search.md) — Open search with a keyboard shortcut and jump to a document by name.

## Story

- [Metadata](story/metadata.md) — What the Metadata sidebar holds for each resource: built-in and custom fields, subtypes, prose diagnostics, tags, and where project-wide settings live.
- [Metadata Queries & Smart Folders](story/metadata-queries.md) — Build queries over a project's metadata with filter chips and save them as smart folders.

## Views

- [Organizer View](views/organizer.md) — Shows a folder's contents as a board of cards that can be filtered and reordered.
- [Data View](views/data.md) — A project dashboard with resource and word totals, a table of resources by status, and a list of resources.
- [Diff View](views/diff.md) — Compares a document's canonical revision with another revision and marks the differences.
- [Timeline View](views/timeline.md) — Shows dated scenes as chips on a horizontal story-date axis, with zoom, point-of-view colors and folder rows.
- [Entities View](views/entity-roster.md) — A project-wide list of declared entities with their kind, aliases, mention counts and any needs-attention flags.
- [Relationship Graph View](views/entity-relationship-graph.md) — A project-wide graph of declared entities and the connections between them, with settings, saved node positions and a focal point.

## Protect and finish

- [Revisions](protect-and-finish/revisions.md) — Every text document keeps a history of saved revisions that you can name, protect, switch between and clean up with the prune command.
- [Trash](protect-and-finish/trash.md) — Deleted resources and folders go to a project Trash tab, where they can be restored or permanently deleted.
- [Resources and Resource Types](protect-and-finish/resources.md) — What a resource is, the four kinds (document, image, audio, folder) and what each one shows in the Work Area and the sidebar.
- [Compiling Projects](protect-and-finish/compiling.md) — Compile a project, or just the documents tied to one entity, into a single txt, md, pdf or docx file.
- [Project Configuration](protect-and-finish/project-configuration.md) — The project.json file in each project's folder, the keys it holds and the defaults a new project starts with.
