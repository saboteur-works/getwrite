# Start Page

The Start Page is the first thing you see when you open GetWrite — your home base across all your writing.

## Your projects at a glance

Every project you've created is listed here, along with running totals of how many projects and resources you've made. It's a quick way to take stock of your work and pick up where you left off.

## Working with projects

From the Start Page you can act on a project without opening it first:

- **Create** a new project — you'll choose a [project type](project-types.md) and give it a name.
- **Open** a project to start writing.
- **Rename** a project.
- **Delete** a project you no longer need.
- **Compile** a project into a single output. See [Compiling Projects](compiling.md).
- **Import** a Scrivener 3 project (created on a Mac) as a new GetWrite project — desktop app only. Choose the `.scriv` project, name the new project, and GetWrite carries over its folders, documents, and metadata, then shows a report of anything it couldn't convert.
- **Import Word Document** — desktop app only. Choose a single `.docx` file or a folder of them, name the new project, and GetWrite converts the text (splitting a single file into one resource per heading, by default), then shows a report of anything it couldn't convert.
- **App Settings** — opens a standalone settings dialog that isn't tied to any one project and needs no login or account. Today it manages your cross-project list of custom noise words, used everywhere GetWrite flags an entity name or alias as risking false matches (see [Entities View](views/entity-roster.md)). This list lives on this device/install only — it isn't synced between desktop, web, and mobile. In the desktop app it also holds the **Home network sharing** controls (not yet released), described in [Home-network sharing](../features/home-network-sharing.md).

Keeping these actions in one place means less time managing files and more time writing.
