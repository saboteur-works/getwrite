# android/ (getwrite-android)

Paths relative to `android/` unless prefixed `frontend/`. Capacitor Android shell, sibling to `electron/`; design in `docs/architecture/ADRs/adr-021-native-android-via-capacitor-in-process.md`.

- `capacitor.config.ts` `webDir` is `../frontend/out`, the frontend static export.
- `pnpm --filter getwrite-android build` is a placeholder (logs a message); there is no Gradle build. CI `.github/workflows/build-android.yml` runs only that placeholder, not `build:native`.
- The app build is on the frontend: `pnpm build:native` (`GETWRITE_BUILD_TARGET=native`, `frontend/scripts/build-native-static.mjs`) copies `app/` minus `app/api/**` and the hosted-auth pages into `frontend/.native-build/` (never mutating `app/`), runs `next build` there with `output: "export"` (`frontend/next.config.mjs`), and emits `frontend/out/`. `app/(app)/layout.tsx` skips the auth redirect on native; `.browserslistrc` pins Chrome >= 67. Pages excluded from native are listed in `EXCLUDED_APP_SUBPATHS`.
- `frontend/getwrite-config` is a generated, gitignored link (symlink, or junction on Windows) to repo-root `getwrite-config/`, created by `frontend/scripts/ensure-config-link.mjs` (postinstall, prebuild, pretypecheck, native build).
- Runtime: `NEXT_PUBLIC_GETWRITE_RUNTIME === "native"`; root-layout `NativeBootstrap` calls `native-bootstrap.ts`; every `lib/api/*` and `store/` transport resolves in-process through `createTransport` with `native-*-backend.ts` (+ `.web-stub.ts`). See `frontend/CLAUDE.md`.
- Share target (Feature 107): `android/app/src/main/java/works/saboteur/getwrite/ShareInPlugin.java`, a custom Capacitor plugin registered by hand in `MainActivity.java` (`registerPlugin`), so it is not in the synced plugin list and needs no dependency. `android/` here is the tracked Capacitor project `android/android/`. Manifest filters on `MainActivity` (`singleTask`): `SEND text/plain`, `SEND image/*`, `SEND_MULTIPLE image/*`, each with category `DEFAULT`; no video filter. The plugin reports metadata only (text, or image URI, MIME type, name, size) as a retained `shareReceived` event with a `shareId`; it opens no stream and makes no staging copy (no `openInputStream`, `getCacheDir` or `getFilesDir`). The web layer reads the `content://` bytes after a project is chosen (`frontend/src/store/transport/shared-content-reader.ts`) and calls `acknowledge({ shareId })`, which sets the intent's action to `MAIN` and clears it. Contract: `frontend/src/lib/api/share-capture-types.ts`.
- Delivery rules: `BridgeActivity.load()` calls `onNewIntent(getIntent())`, so the plugin drops an intent object it already reported (cold start). `MainActivity.onCreate` replaces the launch intent with a plain `MAIN` one when `savedInstanceState` is non-null, so a relaunch from Recents after process death does not redeliver a share (device-measured, Pixel 7 Pro). A relaunch from Recents after a reboot, where saved state may be absent, was not run. `MainActivity` logs `savedState`, action and flags on create (tag `ShareIn`) on purpose.
- Native storage has no encryption layer; the encrypted-marked project guard is `native-encrypted-project-guard.ts`. See `docs/features/inbox.md`.
